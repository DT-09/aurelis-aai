# Commercial operating model

AURELIS sells an assurance outcome rather than generic dashboard access.

An initial engagement can include system scoping, baseline establishment, representative change validation, remediation guidance, retest, and an evidence package. Ongoing access can be provisioned through tenant entitlements.

Payment automation is intentionally not represented as live until the merchant/provider account, credentials, webhooks, and applicable eligibility requirements are configured. Operator-side manual payment recording and provisioning are supported.
